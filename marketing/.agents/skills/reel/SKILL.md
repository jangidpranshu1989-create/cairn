# Reel / Short script

1. Pick the next unused idea from `drafts/week1/reels.md` ideas list (or the owner's topic). Check tracker so we don't repeat.
2. Output in this format and save to `drafts/reel-<NN>-<slug>.md`:
   - Hook (0-2 s): on-screen text + first line spoken. Show the result first, never the logo.
   - Shots (screen recording on a real phone, 9:16): numbered, with what to tap/say and on-screen text.
   - Voiceover lines in Hinglish, casual, 2.5 words/sec max.
   - CTA (last 3 s): "Free hai, link bio me" (bio link = `scripts/link.sh instagram bio index.html`; YouTube: `scripts/link.sh youtube <reel-slug>` in description/pinned comment).
   - Caption (≤ 150 chars) + 5-8 hashtags from channels.md.
   - Cover text (3-4 words).
3. Rules: demo only features in facts.md; record on real phone with 4G/home WiFi (stores block datacenter IPs); no fake prices; blur personal address/phone; keep payments at fingerprint screen, never show a real UPI PIN.
4. Suggest trending audio type (no specific copyrighted song names required) and best time 7-10 pm IST.
