# SEO / content

1. Keyword ideas: "best AI browser India", "free AI browser Android", "Comet browser alternative free", "Chrome Gemini alternative", "Amazon Flipkart price compare app", "Hindi AI assistant app", "AI shopping assistant India".
2. For a keyword: write title (≤ 60 chars), meta description (≤ 155), H1, outline, 700-1,200 word article that genuinely helps (honest comparison table, how-to steps, screenshots), FAQ (4-6 Q&A), and internal links to `/download.html`, `/features.html`, `/security.html`.
3. Only claims from facts.md; competitor facts need a cited source link and date.
4. Website pages are generated by `tools/build_site.py` in the repo root; tell the owner the page is ready in `drafts/seo-<slug>.md` and, if he agrees, add it via the site builder in a separate commit.
5. Cross-post versions to dev.to/Hashnode with canonical URL pointing to the website; tracked link `scripts/link.sh devto <slug>`.
